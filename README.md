# RPG Shop & Inventory System

A lightweight, text-based Python program that simulates an interactive RPG shop and inventory management system.

## 🎮 Features
* **Interactive Shop Loop:** Browse available shop items with clear price listings and menu prompts.
* **Gold & Transaction System:** Automatically checks gold balances and deducts currency upon successful item purchases.
* **Dynamic Inventory Tracking:** Appends newly acquired items directly into the player's inventory list.
* **Input Validation:** Handles invalid user inputs cleanly to prevent runtime crashes during shop loops.
